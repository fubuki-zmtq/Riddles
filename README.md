# ZMTQ 謎解きウェブサイト プロトタイプ

## 起動方法
JSONをfetchするため、`index.html`の直開きではなくローカルWebサーバーで起動してください。

### Pythonがある場合
このフォルダーで次を実行します。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

### GitHub Pages
リポジトリ直下へ全ファイルを配置し、Settings > Pagesから公開します。

## 確認できる機能
- JSONによるステージ・問題・更新情報管理
- NORMALクリア後のHARD解放
- SHA-256ハッシュによる正解判定
- LocalStorageによるクリア状態・実績保存
- URLパラメータによるステージ直接表示
- ヒント、モーダル、X共有、更新検知
- PC・スマートフォン向けレスポンシブ表示
